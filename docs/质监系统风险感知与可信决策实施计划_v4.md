# 质监系统风险感知与可信决策实施计划 v4

> 当前实施口径：多源质量数据驱动的风险感知与可信决策平台
> 四个业务 Agent：市场监控、舆情监测、监督抽查、实验室检测
> 风险研判：共享业务对象，不是第五个 Agent
> 实验室检测：按组织功能开关启用的抽查验证能力

## 1. 统一业务主线

```text
多源数据接入
→ 来源登记、去重、规范化和证据生成
→ 风险线索形成
→ 市场监控与舆情监测并行分析
→ 风险研判与独立专家复核
→ 监督抽查策略
→ 可选实物样品和设备验证
→ 处置反馈与知识更新
```

产品身份采用“产品类别 → 具体产品/型号”。SKU、条码、来源产品编号作为外部标识；真实生产批次和单件序列号只在来源明确提供时记录。图片是证据/数据样本，不自动创建实物样品。

## 2. 申报目标与系统能力映射

| 目标 | v4 系统能力 | 真实验收条件 |
|---|---|---|
| 多源异构数据基座 | 来源、导入任务、原始记录、附件和证据统一契约 | 取得真实业务数据授权与台账 |
| 风险精准感知 | 风险案件、风险政策、证据引用、等级草稿和专家复核 | 独立标注集与业务专家复核 |
| 标准合规核验 | 标准文档、条款定位、标准执行规则 | 权威标准、条款和规则审核 |
| 态势动态推演 | 市场监控汇总统一来源和已确认风险 | 销量/在用量等真实分母与历史窗口 |
| 抽查策略优化 | 已复核风险到约束抽查计划 | 真实预算、人员、地区和执行反馈 |
| 抽查过程优化 | 可选设备观测、证据状态、补测和停止建议 | 真实设备协议、正常基线和完整检测对照 |
| 多智能体协同 | 四 Agent 固定名称和统一 Manager 调度 | 四场景真实输入、输出和审计记录 |
| 可信决策 | 来源哈希、证据定位、版本、冲突、人工复核 | 校准集、误差报告与处置反馈 |

## 3. 已实施的 v4 接口

- `/quality-products/*`：产品类别、具体产品和外部标识。
- `/quality-data/sources`：来源登记和接入方式。
- `/quality-data/imports`：CSV/XLSX/JSON 预览、确认和取消。
- `/quality-data/events`：API/Webhook/人工录入统一事件。
- `/quality-data/attachments`：图片、视频、PDF和文档附件。
- `/quality-data/records/*`：原始资料和证据查询。
- `/risk-cases/*`、`/risk-assessments/*`：风险线索、研判草稿和独立复核。
- `/risk-policies/*`：风险政策版本和发布。
- `/standard-execution-rules/*`：标准条款到可执行条件。

## 4. 页面与权限

业务菜单固定为：质监工作台、数据接入、市场监控、舆情监测、风险研判、监督抽查。实验室验证默认隐藏，组织明确启用后才进入抽查验证流程。通用任务和通用结果继续作为平台通用能力。

管理员维护产品类别与产品、监管企业、数据来源、标准与条款、标准执行规则和风险政策。地区使用内置行政区划和浏览器定位，不设置用户维护的地区字典。

## 5. 数据与结论边界

- 没有真实生产批次时保持为空，不生成伪生产批次。
- 缺少产品型号、批次或序列号不阻止类别级风险研判。
- 没有校准集时风险概率保持未知。
- 情绪强度不能直接转换成风险等级。
- 实验室提前停止只结束本轮采集，不代表结果签发。
- 工程测试不能替代真实数据、模型、设备和业务指标验收。
