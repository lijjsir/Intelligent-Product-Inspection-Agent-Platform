# 质监分页与查询验收

日期：2026-10-18。仅本地修改和提交，保持现有目录，没有推送或远程部署。

## 已完善的范围

- 报告中心改用游标分页和标题搜索。每页只返回摘要，批量核对当前访问范围，不逐份调用报告详情、不读取附件原件；打开或导出报告时仍完整核对来源、版本和授权。列表明确显示“生成时快照，打开核对当前依据”，不把未经实时核验的摘要显示为当前有效结论。
- 报告中心与实验室页面的来源事项支持按编号或标题搜索、翻页；当前事项即使不在当前页，也保留已核对的名称。
- 实验室任务和接入检测资料分别分页、搜索，按组织、演示/正式环境及同一产品过滤；没有产品时，资料可按同企业过滤。已选项目独立核对，不受当前搜索和页码影响；撤权或对象不匹配后清除旧名称并提示不可访问。关联动作继续执行既有门禁，不自动启动检测。
- 报告翻页和搜索不重读当前报告的完整证据；读取失败移除旧报告内容。切换事项、迟到响应、并发修改及重复操作沿用原有保护。搜索和事项读取错误交由页面处理，避免过期请求仍弹出全局错误提示，当前请求的失败继续可见。
- 补齐协同与会议室绑定检查，关联已变化时不继续展示上下文。报告摘要批量检查同样的参与范围和有效房间成员关系。
- 市场监控中折叠的“已确认风险与抽查统计”改为首次展开时加载，避免进入市场监控就触发后台态势分析。统计的原有功能和权限保留。

没有新增数据库表或迁移，没有覆盖原有 `.env` 或业务资料。

## 接口与兼容

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/risk-report-pages` | `case_id` 可选，`keyword` 最多 200 字，`size` 默认 20、最多 50，`cursor` 可选；返回 `items/next_cursor/has_more/size/notice` |
| `GET /api/v1/risk-cases/{case_id}/laboratory-tasks-options` | `page/size/keyword/selected_ids`；每页默认 20、最多 50；重复 `selected_ids` 参数一次最多 20 个 |
| `GET /api/v1/risk-cases/{case_id}/laboratory-records-options` | 同上；返回 `items/total/page/size/selected/unavailable_selected_ids` |
| `GET /api/v1/risk-cases` | 继续使用现有分页，同时支持事项编号和标题搜索；同创建时间按 ID 稳定排序 |

报告以创建时间、ID 降序取下一段数据；游标加密，绑定组织、账号、环境、事项、关键词和页大小，一小时过期。筛选变化、篡改或过期会明确报错，页面提供回到首页。当前授权另按请求重新检查，不依赖游标中的旧权限。

单次报告读取限制扫描数量，授权失效的报告不会返回摘要。某页可能没有可访问记录但仍有下一页，界面允许继续翻页；不提供会误导用户或泄露隐藏报告数量的全局总数。新增报告从首页查看；既有记录在翻页期间新增报告时不会重复。

旧路由保留：`/risk-reports` 仍返回数组，但最多 50 条摘要，并通过响应 `warnings` 提示完整浏览应使用新接口；旧 `/laboratory-options` 每类最多 100 条，带 `truncated` 标识。新的业务界面不依赖这两个有界兼容列表。

## 本地 MySQL 并发检查

脚本：`backend/scripts/benchmark_quality_pagination.py`。只允许连接带演示所有权标记的隔离库，并要求测试表使用 InnoDB。每个会话禁止提交，所有合成数据在事务内使用后回滚；异常和超时同样清理。执行前后比较九类表的组织记录数量。

```powershell
docker compose --env-file .env.quality-demo -f compose.quality-demo.yml exec -T backend python -m scripts.benchmark_quality_pagination --reports 1000 --readers 4 --pages 8
```

本次结果：4 个并发会话，各 1000 份合成报告，共计时 32 次报告分页请求，平均 **59.18 ms**、P95 **75.24 ms**、最大 **75.36 ms**。一个会话额外枚举全部 1000 份报告且无重复，各会话均能找到超过首 200 项的任务、资料和事项。MySQL 下附件通过另一授权来源共享的查询同时验证通过。所有事务回滚，基线数量一致，原件读取、模型调用和业务复核均为零。

这是本机 MySQL 的服务层检查，合成快照较小；不包含 HTTP、文件读取、完整详情核验、真实模型、仪器、生产数据分布或长时间负载，不能用此数值承诺生产容量。
