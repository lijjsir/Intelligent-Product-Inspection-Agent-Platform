# 检测结果回流与专家导航整理

实施日期：2026-10-18。仅修改并重载本地代码，没有远程部署、Git 推送或凭据调整。

## 使用结果回流

1. 专家打开来源风险事项，在“可选验证”中选择需要验证，关联已有的同一产品检测任务。
2. 在“从检测任务返回已复核结果”中选择结果，填写回流说明，再点击“将已复核结果返回原事项”。列表分页读取，无权使用、原件失效或依据失效的结果会说明原因并禁止选择。
3. 返回事项创建新版研判。服务端自动带入全部有效回流结果，无须重新录入报告或结果，也不另建风险事项、检测任务或重复的资料记录。
4. 另一位专家独立复核新版研判，再基于新版完成同单位协同、形成新建议和报告。旧版本、原复核意见与旧报告快照继续保留。
5. 需要移除引用时，验证编写人或本次回流人填写理由并点击“撤回本次结果引用”。这不删除原检测结果，事项需要重新研判；重新使用已撤回结果也须明确重新回流。

## 边界与保存

- 正式业务只接受同组织、同一产品、批次/单件范围相符、经另一位专家独立复核的原生检测执行结果。检查原件、报告共享授权、标准要求、任务范围、样品、复核凭据、项目计算和冻结版本。
- 检测复核范围内的私人报告不会自动变成风险协同共享资料。回流要求原报告明确共享到业务范围。演示任务和演示运行不能进入正式事项，演示环境继续使用模拟资料回流。
- 保存原任务、原检测执行、报告/附件及版本摘要的引用，不把同一个来源复制为新的受理资料。回流说明固定，重复点击返回原关联；不同说明不能静默覆盖。
- 以验证记录修订号及候选结果摘要检查并发版本冲突；先锁定原事项，再处理验证关联，成功响应前提交事务。旧结论在回流、来源失效或撤回引用后不能继续作为当前有效抽查依据。
- 撤权后隐藏回流历史的结果摘要和说明，保留必要关联和撤回入口。旧报告、导出和直接文件读取仍重新检查授权。
- 模型输入会收到已核验项目摘要和可追溯编号；未知发生时间仍为未知。所选项目判定不等于产品整体结论，不自动填入发生概率或代替风险复核。
- 新报告包括回流编号、任务、结果、版本、原始资料/附件索引及限定范围。正式导出修复类型和标签，并使用新版渲染标识，避免复用带演示标签的旧文件；演示导出复用规则兼容。
- 修复正式事项失效后，带协同引用的旧报告读取异常；旧报告正常保留为历史快照。

新接口：

- `GET /api/v1/risk-laboratory-verifications/{link_id}/execution-results?page=1&size=20`，每页最多 50 条。
- `POST /api/v1/risk-laboratory-verifications/{link_id}/execution-results`，提交 `expected_revision`、`run_id`、`expected_run_hash`、`note`。
- `POST /api/v1/risk-laboratory-verifications/{link_id}/execution-results/{return_id}/withdraw`，提交 `expected_revision` 与 `note`。

引用与操作记录使用既有验证关联的 JSON 数据，没有新增数据库表或迁移。

```text
  标准审核 / 知识资料

```

按后续明确意见，质量监督收纳总览和四个业务入口，工作台本身不再承载子菜单。实验室检测只有一个入口，检测任务、检测结果、协同中心和报告中心分别独立，AI 对话置顶。对话页也直接显示完整平台导航，移除“展开平台功能”按钮；历史对话与个人设置继续可用。

专家有业务权限时默认进入质监工作台；无对应权限时按已有权限规则选择入口。分组点击只展开或折叠，不离开正在处理的页面；进入页面或刷新会展开对应分组，抽查建议等详情路由高亮正确模块。其他角色保留原导航和展开规则，现有路由及业务关联不删除。

## 验收范围

- `test_risk_execution_return.py` 使用真实业务服务和内存数据库，覆盖回流、新版自动引用、独立复核、新建议/报告、旧快照、同结果去重、多结果保留、撤回与更新、标准/来源/原件失效、权限、跨组织、版本冲突、模型输入、接口和正式导出元数据。
- 隔离测试使用标明用途的测试 PDF 和测试依据；没有将虚构的正式检测资料写入本地业务库或演示案例。本轮没有调用真实模型或仪器。
- 正式业务界面以隔离 API 契约验证回流选择、分页、冲突、重复禁用、撤回和手机布局。真实演示 API 另行验证专家菜单、展开行为、深链、刷新和移动导航。
- 原演示 MySQL 接口及浏览器导出复验保留：16 条资料、6 个研判版本、3 份报告，没有新建正式计划或检测任务。
- 新导出通过 PDF/Word 文本、PDF 页面图像与 Word 结构检查。结果见 `RESULT_RETURN_CHECKS.json`；日志、截图、账号和导出文件均在忽略的 `.codex_tmp/` 中。

## 尚需真实业务验收

本轮是专家明确触发结果回流，没有增加任务结束后自动写入风险结论的后台动作。真实转录值、标准适用性、业务人员操作和仪器数据仍需现场验收；隔离测试不能证明这些事实正确。全平台完整分页、生产规模并发压测、真实手机及 Safari 验证仍待继续。
