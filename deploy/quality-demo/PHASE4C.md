本轮仅完成本地阶段 4C。最新演示研判、同单位协同和抽查建议已经连接；实验室验证与独立研判报告留在阶段五。

## 查看与操作

使用 `demo_analyst` 或 `demo_reviewer` 登录：

<http://127.0.0.1:15174/app/sampling-plans?case_id=90daba62-f80d-55b5-9d25-f05d0c0ffdfe&suggestion=3f07f23f-c64e-5ae9-91ed-8fdc23e1bf5a>

也可以从事项的“抽查建议”页签进入，或使用左侧“监督抽查”。只有服务端确认是指定隔离演示环境时，现有抽查路由显示本页。正式环境继续使用原抽查计划流程；运行环境身份加载失败时不会默认显示正式操作。

当前 `DEMO-QS-001` 第 5 版演示复核通过，关联一个已完成的同单位协同和一条已固定的演示抽查建议。编写人为 `demo_analyst`；`demo_reviewer` 可查看及追溯。仍为一个事项、五个研判版本、15 条事项来源、16 条证据，没有复制原始资料或增加检测任务。

操作流程：

1. 最新人工演示版本须由另一位专家独立复核通过，资料指纹有效，且本版协同工作项已完成，才进入演示候选。
2. 点击“编写演示建议”，固定事项/版本、产品与企业引用、来源/证据 ID、结论、缺口、限制、独立复核和公开协同意见。
3. 编写抽查理由、关注内容、资源假设及限制。样本数量、批次、地点和建议时间未知时留空，保存为 `null`，不自行生成正式标准或测量结论。
4. 保存后可刷新恢复；编写人显式“确认并固定演示建议”后，内容不可覆盖，状态为 `demo_confirmed`。这一步固定建议文本，不替代独立风险复核。
5. 从建议返回原事项时固定原研判 ID 与协同页签；原始资料链接仍访问同一受理记录及其附件。

## 版本与访问边界

- 只允许指定本地演示组织中有效、受邀的专家，沿用质量资料、会议和协作权限。逐次校验原会议成员范围；管理员及非受邀者不能通过建议接口读取讨论快照。
- 使用现有 `supervision_records` 的独立 `demo-sampling-suggestions` 类型；没有新增表，不写入正式 `sampling-plans`。
- 相同来源上下文使用固定指纹及组织内唯一键，重复/并发创建返回同一条建议。保存要求修订号，冲突返回 409；只有编写人可保存、固定。
- 原始资料、附件、对象、证据、最新研判、复核记录以及公开协同意见变化会使旧建议显示“待重评”。原文本、固定时间和快照保留。新上下文可另建建议，不改绑原记录。
- 快照包含全部公开会议消息和工作项评论，不受事项面板最近 50 条展示上限影响。生成时已撤回的消息只带入撤回提示；固定后消息再撤回，旧快照保留并标为待重评。私聊和旁路提问不进入快照，也不会因普通私聊增加而更换来源上下文。
- 正式候选仍要求真实证据核验和正式 `accepted`，没有降低规则。演示建议不会启动抽查/实验室检测、正式风险统计或知识发布。
- 本轮为人工流程，`llm_called=false`。真实数据、真实模型和标准适用性仍需单独验收。

## 接口

路径前缀均为 `/api/v1`：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /demo-sampling/candidates?case_id=…` | 演示候选和不符合条件的原因 |
| `GET /demo-sampling/suggestions?case_id=…` | 可访问的演示建议及当前有效性 |
| `GET /demo-sampling/suggestions/{id}` | 固定快照、内容和操作记录 |
| `POST /risk-cases/{id}/demo-sampling-suggestions` | 指定研判、协同和上下文指纹，幂等创建 |
| `PATCH /demo-sampling/suggestions/{id}` | 编写人按修订号保存 |
| `POST /demo-sampling/suggestions/{id}/confirm` | 校验当前依据、必填文字后固定 |

输入不接受组织切换、正式状态、模型成功标识、风险概率或执行任务 ID。没有直接删除或覆盖已固定记录的接口。
